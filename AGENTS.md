# Zeno v2.0.0 — AI Video Editor

Use `.venv/bin/python` (macOS/Linux) or `.venv\Scripts\python.exe` (Windows) as `<PY>`. Zeno v2.0.0 uses the **Host-AI Direct workflow** (zero MCP servers, direct Host-AI planning). Process 1, 2, or 3+ videos **sequentially one by one** until every video is delivered to `~/Downloads/Zeno Outs/<Name>/`. Never poll background jobs (`sleep`, `write_stdin`, `manage_task`); if a command backgrounds, end your turn and wait for async wakeup, otherwise wait for each command to finish. For missing initial inputs, run `<PY> scripts/zeno.py --preflight --compact` and ask only for what is missing.

## Zero-Yes/No & Diagnostic Rules (Mandatory)
- **Zero Yes/No or Option Prompts**: NEVER ask Yes/No questions, numbered options (`1/2/3`), `"tell me to go ahead"`, or `"Should I proceed?"` — including when `--inspect` reports `[INCOMPLETE CLIPS]`, sparse transcripts, or `[ORDER BLOCKED]`. Diagnose, retry, repair, and deliver automatically.
- **Auto-Retry Incomplete Clips**: `--inspect` already retries incomplete clips once inside the same command (`[AUTO RETRY]`), so never repeat `--retry-incomplete` manually unless `[INCOMPLETE CLIPS]` appears without `already retried`, or `editing_packet.md` shows `untranscribed_speech` / missing candidates with uncovered speech — in which case immediately inspect `<PY> scripts/edit_packet.py work/<project> --diagnose` (and `--clip "<name>"` if needed) and automatically run `<PY> scripts/zeno.py "<footage>" --script "<script>" --name "<Name>" --inspect --retry-incomplete --compact` (or `<PY> scripts/zeno.py work/<project> --retry-incomplete --compact`) without asking permission.
- **Never Read Raw Clip Caches or Write Scratch Scripts**: Never attempt to read `work/_clips/**` directly (denied by design), and never write `/tmp/*.py` scratch scripts; always use `<PY> scripts/edit_packet.py work/<project> --diagnose`, `--clip "<name>"`, and `--lines <ID,ID,...>`.
- **Preserve Healthy Caches**: Never use `--fresh` unless every single clip actually needs re-transcribing; prefer `--retry-incomplete` or `--clip "<name>"`.

## Host-AI Direct Workflow

### Single Video
1. **Inspect**: `<PY> scripts/zeno.py "<footage>" --script "<gdoc_tab_url_or_path>" --name "<Name>" --inspect --compact`. `--inspect` already retries incomplete clips once inside the same command (`[AUTO RETRY]`); run `--diagnose` / `--retry-incomplete --compact` manually only if `[INCOMPLETE CLIPS]` appears without `already retried` (or `editing_packet.md` shows `untranscribed_speech` / missing candidates with uncovered speech).
2. **Read Once (1 batch)**: Read **only** `work/<project>/editing_packet.md` (or `editing_packet_p*.md` if chunked) and `work/<project>/clip_sheet_*.jpg` in one batch. Never open `formats/*`, `scripts/*`, `facts.md`, `line_map.md`, `clip_caches.json`, or `work/_clips/**`. (For any **2nd+ video in the same chat**, isolate it in a fresh subagent per the section below instead of loading another packet here.)
3. **Plan**: Write `work/<project>/script_analysis.md` (`Format: <id> (<title>)` on line 1) and `work/<project>/plan.edl` (plus `work/<project>/decisions.txt` only if needed for genuine unscripted gaps, e.g. `accept <id> <reason>`).
4. **Execute, Repair & Deliver**: `<PY> scripts/zeno.py --execute work/<project>/plan.edl --square --compact` — validates script order/cuts/voices, snaps pauses, renders `9:16` + `1:1` + Premiere `.prproj`/`.xml`, runs Deep QC (`review_sheet.jpg`), delivers to `~/Downloads/Zeno Outs/<Name>/`, and triggers automatic desktop sound & popup notification. On `[BLOCKED]`, the output already carries `[LINE DETAILS]` (candidates and measurements for every blocked line) and `[CUTS   WHERE]` for a failed render check: fix **every** listed line/cut in **one** `plan.edl` edit and re-run `--execute` once (no one-line-at-a-time fixes, no separate lookups, and never write `/tmp/*.py` scratch scripts). Only if a detail is missing, run `<PY> scripts/edit_packet.py work/<project> --lines <ID,ID,...>` (or `--diagnose` / `--clip "<name>"`); never re-read the whole packet. Inspect `~/Downloads/Zeno Outs/<Name>/review_sheet.jpg` once.

### Multi-Video Queue (`2+` videos) & Sequential Same-Chat Videos
1. **Inspect All (Upfront Queue)**: For `--queue <queue.json>` (`2+` videos upfront), run `<PY> scripts/zeno.py --queue <queue.json> --inspect-only --compact` (e.g. `work/queue.json`) to prepare every queued video's compact packet outside the main chat.
2. **Isolate 1 Fresh Subagent Per Video**: Spawn **1 fresh isolated subagent per queued video** — and whenever the user requests a **2nd+ video in the same chat** after an earlier video's packet/sheets were loaded — returning only `~/Downloads/Zeno Outs/<Name>/` + status so prior `editing_packet.md` and `clip_sheet_*.jpg` stay out of the active loop and are never re-read across subsequent edits. Each subagent runs Inspect (if not pre-inspected, auto-retrying incomplete clips once via `[AUTO RETRY]`) -> Read Once -> Plan -> `--execute work/<project>/plan.edl --square --compact` + all-lines-in-one-edit repairs from `[LINE DETAILS]` / `[CUTS   WHERE]` (`scripts/edit_packet.py work/<project> --lines <ID,ID,...>` only if a detail is missing) until delivered to `~/Downloads/Zeno Outs/<Name>/` with automatic desktop sound & popup notification. Fix any `[BLOCKED]` line before starting the next video.

## Editorial & Technical Invariants
- **Script Order & Sentence Integrity**: Play every spoken line once in script order with `sp="ExactSpeaker"`; keep every spoken sentence complete from first syllable (`start - 0.05s`) through full final syllable decay (`end + 0.06-0.10s`, verified against `pauses:` in `editing_packet.md`). NEVER cut or excise `<0.45s` mid-sentence breaths or commas; only trim genuine dead-air pauses `>=0.50s` (`>=0.55s` inside `split_h`/`split_v`), `! REPEAT / STUMBLE`, and scripted laughs/cries `>1.2s` (`<=1.2s` kept), joining turns `0.06-0.15s`.
- **Splits & Motion**: `split_h`, `split_v`, `top_pip`, and baked splits are ALWAYS `z=1` with `14%` headroom and advancing silent listener (`peer="Name:clip.mp4"@in-out@side`); for `single` `1.08` punch-in emphasis, either punch in at a real `>=0.45s` pause in `pauses:` or use `z=sudden_in:1.08@t` inside the continuous cut without slicing the audio; turns `>=2.5s` -> smooth `1.0->1.06` push; pass `focus=x,y` from the packet.
- **Transitions, Marks & Banners**: Add `+1-2` purposeful story-driven transitions/reel on real scene/location/act shifts (dialogue cuts stay crisp hard cuts; zero intra-split, same-shot, or mid-line transitions). Use script-accurate `✓`/`✗` marks with live non-frozen video visuals during post-word marks/SFX without dialogue overlap, `card:"English | Native"` for `Flashcard Text:`, and `banner:` only for Stop Saying strikethrough; zero fake `"Install Now"` CTA buttons; keep bottom `20-25%` CTA-safe; zero continuous BGM by default (`-10.5 LUFS`).
- **Subtitles & 1:1 Square**: Default `#subs auto y=65` (strict single-line subtitles only, `54px` at `1080w`; `y=50` on `split_v`), or `#page scroll` (replaces `#subs`, banners, marks, SFX). `--square` 1:1 is always a 2-layer 5–10% Gaussian blur wrap of the completed `9:16` reel (no separate 1:1 images, flashcards, timestamps, or subtitles).
- **Deliverables (`~/Downloads/Zeno Outs/<Name>/`)**: `reel_<Name>.mp4`, `SQ_<Name>.mp4`, `<Name>.prproj`, `<Name>.xml`, `review_sheet.jpg`, `<Name>.plan.edl`, `<Name>.script.txt`.
