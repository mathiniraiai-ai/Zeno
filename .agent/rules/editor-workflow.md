# Zeno — Always-On Workspace Rule

## Hard Rules & `< 1,00,000`-Token 1-Call Workflow
- **Workspace Isolation & Secrets**: Work strictly inside this Zeno repository (team PCs: `~/Documents/Zeno`; owner repo). Never touch other projects in `Documents`, and never open or print `.env`, `.zeno_session.json`, `.zeno_owner_session.json`, or credentials (`<PY> scripts/setup.py --smoke` / `--whoami` only). Never clear caches manually.
- **Multi-Video Queue (`1M` Context) & Notion Naming**: Editors may queue multiple videos back-to-back in one chat session up to **`1M` (`1,000,000` context tokens)** while keeping Notion and Meta connectors enabled; each `--inspect` opens an isolated per-video telemetry/cost window (`INR 40` / `24` requests). Require local footage, script `?tab=...` (or local path), and exact **Notion name** (read from Notion if a Notion card/queue was shared; never invent a name). Deliverables go to `~/Downloads/Zeno Outputs/<Notion name>/` (`reel_<Notion name>.mp4` and `SQ_<Notion name>.mp4`), never inside the repo.
- **Python & Setup**: Always run `.venv\Scripts\python.exe` on Windows or `.venv/bin/python` on macOS/Linux (never bare `python`/`python3`). If `.venv` is missing, run `scripts/install_windows.ps1` (Windows) or `bash install.command` (Mac) once.
- **1-Call Inspect + Auto-Plan**: If inputs are missing, run `<PY> scripts/zeno.py --preflight --compact`, show results, and ask for them. With inputs, run `<PY> scripts/zeno.py --inspect <footage> --script <script> --name "<name>" --auto-plan --compact` (never `--skip-preflight`). This runs live preflight, inspects/reuses clips, runs Zeno's isolated 1-call subscription planner (`claude -p` or `codex exec`, typically `20k–55k` total tokens), checks `--check-plan`, and prints the Pitch Card.
- **Zero Redundant Re-Reads**: When `--auto-plan` passes `[PLAN PASS]`, do NOT re-open `editing_packet.md`, `line_map.md`, `facts.md`, `EDIT_RULES.md`, or `clip_sheet_*.jpg` in the outer chat. Open `editing_packet.md` + `clip_sheet_*.jpg` once only for manual planning, or run `<PY> scripts/edit_packet.py <project> --line L12` (after `<PY> scripts/cost_control.py <project>`) + `--check-plan` for targeted revisions. Script is the timeline; every cut requires `sp="Name"`.
- **Approval, Blocking Render & `review_sheet.jpg`**: Show the concrete plan and obtain Yes/No once (unless queued batch rendering was explicitly pre-authorized). Run `<PY> scripts/zeno.py --execute <plan> --square --compact` as one single blocking/completion-notified run — **never** poll `write_stdin` or progress files in a loop, and **never** write custom FFmpeg/Python frame-extraction scripts (`verify.py` checks 9:16 + 1:1 Square framing and builds `review_sheet.jpg` automatically; inspect `review_sheet.jpg` once or on failure).
- **Owner's Visual Rules (`AGENTS.md`)**: All split screens (including baked splits) stay at `z=1` in fixed frames with 14% headroom and advancing silent listener footage; captions default to `#subs auto y=68` (54 px at 1080 width, 1 row; `y=50` on `split_v`; `adapt=on` only for colour adaptation); `#page scroll` uses `split_h z=1` and replaces captions; transitions only on place/time/layout changes (never inside splits).
- **Token Target**: `< 1,00,000` (`< 100k`) total tokens per video including cache (`20k–55k` typical with `--auto-plan`), isolated per video across up to `1M` multi-video chat sessions.
