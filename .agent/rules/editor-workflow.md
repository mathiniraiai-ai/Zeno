# Zeno — Always-On Workspace Rule

## Hard Rules & `< 1,00,000`-Token Workflow
- **Workspace Isolation & Secrets**: Work strictly inside this Zeno repository (team PCs: `~/Documents/Zeno`; owner repo). Never touch other projects in `Documents`, and never open or print `.env`, `.zeno_session.json`, `.zeno_owner_session.json`, or credentials (`<PY> scripts/setup.py --smoke` / `--whoami` only). Never clear caches manually.
- **Multi-Video Queue (`1M` Context) & Notion Naming**: Editors may queue multiple videos back-to-back in one chat session up to **`1M` (`1,000,000` context tokens)** while keeping Notion and Meta connectors enabled; each `--inspect` opens an isolated per-video telemetry/cost window (`INR 40` / `24` requests). Require local footage, script `?tab=...` (or local path), and exact **Notion name** (read from Notion if a Notion card/queue was shared; never invent a name). Deliverables go to `~/Downloads/Zeno Outputs/<Notion name>/` (`reel_<Notion name>.mp4` and `SQ_<Notion name>.mp4`), never inside the repo.
- **Python & Setup**: Always run `.venv\Scripts\python.exe` on Windows or `.venv/bin/python` on macOS/Linux (never bare `python`/`python3`). If `.venv` is missing, run `scripts/install_windows.ps1` (Windows) or `bash install.command` (Mac) once.
- **Turn 1 — 1-Call Inspect + Auto-Plan + Auto-Render (Primary)**: If inputs are missing, run `<PY> scripts/zeno.py --preflight --compact`, show results, and ask for them. With inputs, run `<PY> scripts/zeno.py --inspect <footage> --script <script> --name "<name>" --auto-plan --compact` (never `--skip-preflight`). This runs live preflight, inspects/reuses clips, runs Zeno's isolated 1-call subscription planner (`claude -p` or `codex exec`, typically `20k–55k` total tokens), checks `--check-plan`, prints the Pitch Card, and automatically renders 9:16 + 1:1 Square without asking Yes/No. When `--auto-plan` passes `[PLAN PASS]`, do NOT open packets/sheets/rules; deliver outputs + token report.
- **Strict Manual / Fallback Cap (4–5 Turns Max, NEVER 40+)**:
  - **Turn 2**: Read `editing_packet_p*.md` (or `editing_packet.md`) + ALL `clip_sheet_*.jpg` in ONE parallel batch.
  - **Turn 3**: Write `script_analysis.md` and `plan.edl` (plus `decisions.txt` if needed) in ONE parallel batch. Script is the timeline; every cut requires `sp="Name"`.
  - **Turn 4**: Never pause to ask Yes/No before rendering (unless the user explicitly requested `--no-auto-render` / plan-only review). Run ONE combined check+render command: `<PY> scripts/zeno.py --execute <plan> --square --compact` (no separate `cost_control.py` + `--check-plan` + `--execute` roundtrips unless `--check-plan` is explicitly needed or the plan fails!). If a command backgrounds, **END TURN immediately** and wait for system completion notification — **never** poll `manage_task`, `write_stdin`, `send_input`, or progress/log files!
  - **Turn 5**: `verify.py` checks 9:16 + 1:1 Square framing and builds `review_sheet.jpg` automatically (never write custom FFmpeg/Python frame-extraction scripts). Read `review_sheet.jpg` ONCE (unless verify fails) and present deliverables + token report. For revisions, log `--feedback "<words>" --plan <plan>` first, then use `<PY> scripts/edit_packet.py <project> --line L12` and `--check-plan` (checking `<PY> scripts/cost_control.py <project>` if manual correction loops repeat).
- **Explicit `[DO NOT]` During Edits**: NEVER open `agent/REFERENCE.md`, `CONCEPT.md`, `agent/EDIT_RULES.md`, `agent/FORMATS.md`, `scripts/*.py`, `clip_caches.json`, `facts.md`, `line_map.md`, `ffprobe`, or `dir`/`Get-ChildItem`/`ls` (`editing_packet.md` already holds syntax card, raw footage inventory, unmatched line diagnostics, and all words/candidates/rules).
- **Owner's Visual Rules (`AGENTS.md`)**: All split screens, including baked splits, stay at `z=1` in fixed frames with 14% headroom. Characters keep their panels; the other character listens silently. Advance listener footage across turns and disclose fallback/loops. Captions default to `#subs auto y=68`, one style and fixed size (54 px at 1080 width), one row. Top/bottom split captions sit at y=50. Colours adapt only with `adapt=on`. Disable only when requested. Scrolling text uses `#page scroll`: two still pictures above a blue rule and a white dialogue page with spoken-word highlight. All cuts `split_h z=1`. The page replaces captions. No extra decorations. Transitions follow changes in place, time or layout. Never inside splits or continuous same-shot dialogue. Marks and banners follow the script. SFX normally -4 to 0 dB; mark exceptions are defined in the brief.
- **Token Target**: `< 1,00,000` (`< 100k`) total tokens per video including cache (`20k–55k` typical with `--auto-plan`), isolated per video across up to `1M` multi-video chat sessions.
