Follow `AGENTS.md` and `agent/DIRECTOR.md`:

1. **Queue & Notion Support**: Queue multiple videos back-to-back in one chat session (up to `1M` / `1,000,000` context tokens) with Notion and Meta connectors enabled; read the exact Notion name from Notion when a card/queue is shared. Each `--inspect` starts an isolated per-video telemetry/cost window (`INR 40` / `24` requests, `< 100k` total tokens including cache, typically `20k–55k`).
2. **1-Call Inspect, Auto-Plan & Auto-Render**: Run `<PY> scripts/zeno.py --inspect <footage> --script <script> --name "<name>" --auto-plan --compact` (or `--preflight --compact` if inputs are missing; never `--skip-preflight`). This runs live preflight, inspects/reuses clips, runs Zeno's isolated 1-call subscription planner (`claude -p` or `codex exec`), checks `--check-plan`, prints the Pitch Card, and automatically renders 9:16 + 1:1 Square without asking Yes/No.
3. **No Redundant File Reads**: Do NOT re-open `editing_packet.md`, `line_map.md`, `facts.md`, `EDIT_RULES.md`, or `clip_sheet_*.jpg` in the outer chat when `--auto-plan` passed `[PLAN PASS]`. Open `editing_packet.md` + `clip_sheet_*.jpg` once only for manual planning, or `<PY> scripts/edit_packet.py <project> --line L12` (after `<PY> scripts/cost_control.py <project>`) + `--check-plan` for targeted revisions.
4. **Owner Visual Invariants**: Keep all splits (including baked splits) at `z=1` in fixed frames with 14% headroom and advancing silent listener turns; default captions to `#subs auto y=68` (54 px at 1080w, 1 row; `y=50` on `split_v`; `adapt=on` only when requested); `#page scroll` uses `split_h z=1` and replaces captions; transitions only on place/time/layout changes, never inside splits.
5. **Auto-Render, Single Blocking Execution & Verification**: Never pause to ask Yes/No before rendering (unless the user explicitly requested `--no-auto-render` / plan-only review). When manual planning/fixes pass `--check-plan`, immediately run `<PY> scripts/zeno.py --execute <plan> --square --compact` as one single blocking/completion-notified run — never poll `write_stdin` or progress files in a loop, and never write custom FFmpeg/Python frame-extraction scripts (`verify.py` verifies both 9:16 and 1:1 Square framing and builds `review_sheet.jpg` automatically; inspect `review_sheet.jpg` once or on failure). Record user feedback verbatim via `--feedback` before revisions.
