Follow `AGENTS.md` and `agent/DIRECTOR.md`:

1. **One Video per Chat**: One video per chat: start each video in a new chat, so every step re-reads a small chat (claude.ai connectors are off, so the editor gives the exact Notion name). The planner makes at most 2 model calls per video. If the output says `[PLANNER STOPPED]` (the planner used its 2 model calls and the plan still fails), do not plan by hand: report the `[BLOCKED]` lines to the editor and ask. Each `--inspect` starts an isolated per-video telemetry/cost window (`INR 40` / `24` requests, `< 100k` total tokens including cache, typically `20k–55k`).
2. **Turn 1 — Primary 1-Call Inspect, Auto-Plan & Auto-Render**: Run `<PY> scripts/zeno.py --inspect <footage> --script <script> --name "<name>" --auto-plan --compact` (or `--preflight --compact` if inputs are missing; never `--skip-preflight`). This runs live preflight, inspects/reuses clips, runs Zeno's isolated 1-call subscription planner (`claude -p` or `codex exec`), checks `--check-plan`, prints the Pitch Card, and automatically renders 9:16 + 1:1 Square without asking Yes/No. When `--auto-plan` passes `[PLAN PASS]`, do NOT open packets/sheets/rules; deliver outputs + token report.
3. **Strict Manual / Fallback Cap (4–5 Turns Max, NEVER 40+)**:
   - **Turn 2**: Read `editing_packet_p*.md` (or `editing_packet.md`) + ALL `clip_sheet_*.jpg` in ONE parallel batch.
   - **Turn 3**: Write `script_analysis.md` and `plan.edl` (plus `decisions.txt` if needed) in ONE parallel batch.
   - **Turn 4**: Never pause to ask Yes/No before rendering (unless the user explicitly requested `--no-auto-render` / plan-only review). Run ONE combined check+render command: `<PY> scripts/zeno.py --execute <plan> --square --compact` (no separate `cost_control.py` + `--check-plan` + `--execute` roundtrips unless `--check-plan` is explicitly needed or the plan fails!). If a command backgrounds, **END TURN immediately** and wait for system completion notification — NEVER poll `manage_task`, `write_stdin`, `send_input`, or progress/log files!
   - **Turn 5**: `verify.py` verifies both 9:16 and 1:1 Square framing and builds `review_sheet.jpg` automatically (never write custom FFmpeg/Python frame-extraction scripts). Read `review_sheet.jpg` ONCE (unless verify fails) and present deliverables + token report. Record user feedback verbatim via `--feedback` before revisions, and use `<PY> scripts/edit_packet.py <project> --line L12` + `--check-plan` for targeted fixes (checking `cost_control.py` if retries repeat).
4. **Explicit `[DO NOT]` During Edits**: NEVER open `agent/REFERENCE.md`, `CONCEPT.md`, `agent/EDIT_RULES.md`, `agent/FORMATS.md`, `scripts/*.py`, `clip_caches.json`, `facts.md`, `line_map.md`, `ffprobe`, or `dir`/`Get-ChildItem`/`ls` (`editing_packet.md` already holds syntax card, raw footage inventory, unmatched line diagnostics, and all words/candidates/rules).
5. **Owner Visual Invariants**: All split screens, including baked splits, stay at `z=1` in fixed frames with 14% headroom. Characters keep their panels; the other character listens silently. Advance listener footage across turns and disclose fallback/loops. Captions default to `#subs auto y=68`, one style and fixed size (54 px at 1080 width), one row. Top/bottom split captions sit at y=50. Colours adapt only with `adapt=on`. Disable only when requested. Scrolling text uses `#page scroll`: two still pictures above a blue rule and a white dialogue page with spoken-word highlight. All cuts `split_h z=1`. The page replaces captions. No extra decorations. Transitions follow changes in place, time or layout. Never inside splits or continuous same-shot dialogue. Marks and banners follow the script. SFX normally -4 to 0 dB; mark exceptions are defined in the brief.
