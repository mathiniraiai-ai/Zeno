Follow `AGENTS.md` (`<PY>` = `.venv/bin/python` on macOS/Linux, `.venv\Scripts\python.exe` on Windows):
- **Zero Yes/No or Option Prompts**: NEVER ask Yes/No questions, numbered options (`1/2/3`), `"tell me to go ahead"`, or `"Should I proceed?"` (even on `[INCOMPLETE CLIPS]`, sparse transcripts, or `[ORDER BLOCKED]`). Never read `work/_clips/**` directly (use `scripts/edit_packet.py work/<project> --diagnose`, `--clip "<name>"`, `--lines <ID,ID,...>`), never write `/tmp/*.py` scratch scripts, and never use `--fresh` unless every single clip needs re-transcribing (prefer `--retry-incomplete` or `--clip "<name>"`).
1. **Single Video**: Run `<PY> scripts/zeno.py "<footage>" --script "<script>" --name "<Name>" --inspect --compact`. Wait without polling. `--inspect` already retries incomplete clips once inside the same command (`[AUTO RETRY]`), so never repeat `--retry-incomplete` manually unless `[INCOMPLETE CLIPS]` appears without `already retried`, or `editing_packet.md` shows `untranscribed_speech` / missing candidates with uncovered speech — in which case automatically run `<PY> scripts/edit_packet.py work/<project> --diagnose` and `<PY> scripts/zeno.py "<footage>" --script "<script>" --name "<Name>" --inspect --retry-incomplete --compact` without asking permission.
2. **Multi-Video Queue (`2+` videos) & Sequential Same-Chat Videos**: For `--queue <queue.json>`, run `<PY> scripts/zeno.py --queue <queue.json> --inspect-only --compact`, then spawn **1 fresh isolated subagent per queued video**. Whenever a **2nd+ video is requested in the same chat** after an earlier video's packet/sheets were loaded, also spawn **1 fresh isolated subagent** for it (Inspect -> Read Once -> Plan -> Execute, returning only `~/Downloads/Zeno Outs/<Name>/` + status) so prior packets and contact sheets stay out of the active loop and are never re-read across subsequent edits.
3. **Plan, Repair & Deliver**: Inside the single-video context/subagent, read **only** `work/<project>/editing_packet.md` (or `editing_packet_p*.md` if chunked) + `work/<project>/clip_sheet_*.jpg` in one batch (never open `formats/*`, `scripts/*`, `facts.md`, `line_map.md`, `clip_caches.json`, or `work/_clips/**`). Write `work/<project>/script_analysis.md` (`Format: <id> (<title>)` on line 1) + `work/<project>/plan.edl` (+ `decisions.txt` only if needed), keeping every spoken sentence complete (`start - 0.05s` through `end + 0.06-0.10s`, verified against `pauses:` in `editing_packet.md` — never cut `<0.45s` mid-sentence breaths/commas; trim only real dead-air pauses `>=0.50s` or `>=0.55s` in `split_h`/`split_v`, and use `z=sudden_in:1.08@t` or a real `>=0.45s` pause in `pauses:` for `1.08` punch-ins without slicing audio), and run `<PY> scripts/zeno.py --execute work/<project>/plan.edl --square --compact` (delivers to `~/Downloads/Zeno Outs/<Name>/` with automatic desktop sound & popup notification; inspect `review_sheet.jpg` once). On `[BLOCKED]`, `[LINE DETAILS]` and `[CUTS   WHERE]` are already in the output: fix **every** listed line/cut in **one** `plan.edl` edit and re-run `--execute` once (no one-line-at-a-time fixes, no separate lookups, never write `/tmp/*.py` scratch scripts); only if a detail is missing, run `<PY> scripts/edit_packet.py work/<project> --lines <ID,ID,...>` (or `--diagnose` / `--clip "<name>"`), never re-read the whole packet.
