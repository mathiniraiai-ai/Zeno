Follow `AGENTS.md` (`<PY>` = `.venv/bin/python` on macOS/Linux, `.venv\Scripts\python.exe` on Windows):
- **Zero Yes/No or Option Prompts**: NEVER ask Yes/No questions, numbered options (`1/2/3`), `"tell me to go ahead"`, or `"Should I proceed?"` (even on `[INCOMPLETE CLIPS]`, sparse transcripts, or `[ORDER BLOCKED]`). Never read `work/_clips/**` directly (use `scripts/edit_packet.py work/<project> --diagnose`, `--clip "<name>"`, `--line <ID>`), and never use `--fresh` unless every single clip needs re-transcribing (prefer `--retry-incomplete` or `--clip "<name>"`).
1. **Single Video**: Run `<PY> scripts/zeno.py "<footage>" --script "<script>" --name "<Name>" --inspect --compact`. Wait without polling. If `[INCOMPLETE CLIPS]` is reported or `editing_packet.md` shows uncovered/untranscribed speech, automatically run `<PY> scripts/edit_packet.py work/<project> --diagnose` and `<PY> scripts/zeno.py "<footage>" --script "<script>" --name "<Name>" --inspect --retry-incomplete --compact` without asking permission.
2. **Multi-Video Queue (`2+` videos)**: Run `<PY> scripts/zeno.py --queue <queue.json> --inspect-only --compact`, then spawn **1 isolated subagent per queued video** (returning only `~/Downloads/Zeno Outs/<Name>/` + status) so packets and contact sheets stay out of the main chat.
3. **Plan, Repair & Deliver**: Inside the single-video context/subagent, read **only** `work/<project>/editing_packet.md` (or `editing_packet_p*.md` if chunked) + `work/<project>/clip_sheet_*.jpg` in one batch (never open `formats/*`, `scripts/*`, `facts.md`, `line_map.md`, `clip_caches.json`, or `work/_clips/**`). Write `work/<project>/script_analysis.md` (`Format: <id> (<title>)` on line 1) + `work/<project>/plan.edl` (+ `decisions.txt` only if needed), keeping every spoken sentence complete (`start - 0.05s` through `end + 0.06-0.10s`, verified against `pauses:` in `editing_packet.md` — never cut `<0.45s` mid-sentence breaths/commas; trim only real dead-air pauses `>=0.50s` or `>=0.55s` in `split_h`/`split_v`, and use `z=sudden_in:1.08@t` or a real `>=0.45s` pause in `pauses:` for `1.08` punch-ins without slicing audio), repair any `[BLOCKED]` line via `<PY> scripts/edit_packet.py work/<project> --line <ID>` (or `--diagnose` / `--clip "<name>"`), and run `<PY> scripts/zeno.py --execute work/<project>/plan.edl --square --compact` (delivers to `~/Downloads/Zeno Outs/<Name>/` with automatic desktop sound & popup notification; inspect `review_sheet.jpg` once).
